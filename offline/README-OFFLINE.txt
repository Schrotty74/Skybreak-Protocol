Skybreak Protocol __VERSION__ – Offline-Version
================================================

macOS:
1. "Skybreak-Protocol-starten.command" doppelt anklicken.
2. Falls macOS den ersten Start blockiert: Rechtsklick auf die Datei, dann "Öffnen".

Windows:
1. "Skybreak-Protocol-starten.bat" doppelt anklicken.

Linux:
1. Im Terminal "./start.sh" ausführen.

Der Starter öffnet das Spiel unter http://127.0.0.1:8765/ im Browser.
Das Terminalfenster muss während des Spielens geöffnet bleiben. Mit Strg+C wird
der lokale Server beendet. Python 3 wird als lokale Laufzeit benötigt.

Alle Spieldateien und zehn Musikstücke sind im ZIP enthalten. Nur die optionale
Prüfung auf neue Beta- oder Final-Versionen benötigt eine Internetverbindung.
