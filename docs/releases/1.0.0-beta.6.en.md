# Skybreak Protocol 1.0.0-beta.6

This beta stabilizes desktop rendering and gives Ultra a consistent GPU effects base. The selected resolution remains constant during a run, removing the brief flicker when moving from the start screen into gameplay. A local performance starter makes it easier to compare Safari and Firefox directly without sending any results anywhere.

## Stable desktop rendering

- Frame pacing now handles browsers running at 80, 96, or 100 Hz correctly instead of accidentally using only every second browser frame.
- Low, High, and Ultra can target 60 FPS cleanly on suitable desktop systems; Medium intentionally remains capped at 40 FPS.
- Ultra uses a fixed render size for the duration of a run. The game and effect surfaces are no longer continuously recreated, keeping the transition from the start screen into gameplay stable.
- The Low profile omits purely decorative panorama, traffic, weather, and grid layers while retaining the complete playable scene, platforms, enemies, and controls.

## Ultra effects and browser comparison

- Ultra renders visible light accents for platforms, enemies, chests, and particles as WebGPU instances in Safari and Firefox.
- In Ultra, rain, light shafts, atmospheric fog, and the neon grid run in the GPU effect surface instead of being duplicated in the main Canvas scene.
- The live indicator shows rendered FPS plus average game-logic and Canvas draw times to help distinguish browser and GPU composition work.
- `Skybreak-Protocol-Performance-Test.command` runs the same local Ultra 4K test scene in Safari and Firefox sequentially. Results remain local in the terminal and are never published.

## Local testing, offline play, and privacy

- `Skybreak-Protocol-Lokaltest.command` remains the normal starter for playing and manual checks.
- The offline ZIP continues to include all music tracks and starters for macOS, Windows, and Linux.
- No accounts, analytics services, advertising, trackers, or additional network requests were added.

## Known beta limitations

- Achievable frame rates still depend on browser, operating system, display, and hardware; Safari and Firefox can compose differently even with the same GPU.
- The local macOS starter requires the project-local Node dependencies. After a fresh checkout, run `npm ci` in the project folder.
