# Skybreak Protocol 1.0.0-beta.7

Diese Beta macht die Leistung auf echten Mobilgeräten direkt sichtbar. Während einer laufenden Partie erscheint auf Touch-Geräten eine kompakte Live-Anzeige über dem Spielfeld. Damit lassen sich Bildrate und mittlere Framezeit bei Hoch oder Ultra prüfen, ohne dass der mobile Kopfbereich oder die Bedienung überladen wird.

## Mobile Performance-Anzeige

- Die neue Anzeige erscheint nur auf Touch-Geräten und nur während einer laufenden Partie.
- Sie zeigt die tatsächlich gerenderten Bilder pro Sekunde sowie die mittlere Framezeit, zum Beispiel `60 FPS · 16,7 MS`.
- Die Anzeige ist nicht bedienbar, verdeckt keine Touch-Steuerung und verschwindet außerhalb einer laufenden Runde.
- Auf Desktop bleibt die bestehende detailliertere Live-Anzeige erhalten.

## Test und Datenschutz

- Die Anzeige hilft beim realen Prüfen von Bildrate, Wärmeentwicklung und Grafikstufen auf iPhone- und Android-Geräten.
- Spielstände, Einstellungen und Messwerte bleiben lokal. Es wurden keine Konten, Analysedienste, Tracker oder zusätzlichen Netzwerkzugriffe ergänzt.
- Das Offline-ZIP enthält weiterhin alle Musikstücke sowie Starter für macOS, Windows und Linux.

## Bekannte Einschränkungen der Beta

- Die erreichbare Bildrate und Wärmeentwicklung hängen weiterhin von Gerät, Browser, Akkustand, Umgebungstemperatur und gewählter Grafikstufe ab.
- Der lokale macOS-Starter setzt bereits installierte projektlokale Node-Abhängigkeiten voraus. Nach einem frischen Checkout genügt `npm ci` im Projektordner.
