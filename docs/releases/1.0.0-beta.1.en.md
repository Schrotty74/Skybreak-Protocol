# Skybreak Protocol 1.0.0-beta.1

The first public beta packages the complete core game as an independent cyberpunk reinterpretation of a vertical arcade climbing game. It includes ten levels, the playable climbing robot, the upgradeable ice pick, scalable graphics modes, and an original techno soundtrack.

## Highlights

- Complete ascent through ten visually distinct cyberpunk levels
- Original playable character: a compact climbing robot with visible mechanical limbs, sensors, antenna, and ice pick
- Choice between power and design upgrades when reaching a new level for the first time
- Adaptive graphics presets from Low to Ultra using Canvas, WebGL2, and WebGPU paths
- Original techno track for the start screen and every level
- Full keyboard controls and adapted touch controls for phones and tablets
- English and German interfaces with direct language switching

## Gameplay and levels

- Break platform modules from below to climb one layer at a time.
- Patrolling drones, gaps, and falling energy fragments form the main hazards.
- Earn points for destroyed platforms, disabled enemies, and reaching the summit.
- Three lives and a locally stored high score support repeated runs.
- Each of the ten levels has its own color palette, atmosphere, and animated background motifs.
- Difficulty can be set separately to Easy, Medium, or Hard for every level.
- Higher difficulty increases enemy speed, hazard density, and the score multiplier.

## Robot and ice pick

- The robot has dedicated walking, jumping, attacking, and idle animations.
- While idle, it examines and playfully spins its ice pick.
- The ice pick can hit enemies and destroy damaged platform modules in front of the robot.
- Power upgrades increase reach and the number of modules destroyed with one attack.
- Design upgrades change the tool's color, shape, and glow.
- The current power and design levels are displayed during play.

## Graphics and performance

- Low, Medium, and High scale frame rate, resolution, rain, fog, traffic, and effect density.
- Ultra adds WebGPU post-processing, stronger bloom, neon reflections, chromatic processing, tone mapping, energy grids, and light rays.
- WebGL2 and Canvas provide compatible fallbacks when WebGPU is unavailable or unsuitable.
- Rendering resolution can scale up to 4K on suitable displays.
- Desktop Ultra adapts between 60, 90, or 120 FPS and adjusts internal resolution according to measured performance.
- Mobile Ultra offers either the more efficient 60 FPS mode or up to 120 FPS.
- Local performance control reduces effects and resolution when frame times remain poor.
- A Web Worker supports effect instances and performance calculations outside the main thread.

## Music and sound

- Ten complete MP3 tracks cover the start screen and all levels.
- Music starts only after user interaction to remain compatible with Safari and mobile browsers.
- A short automatic crossfade changes tracks when moving to another level.
- Music and sound effects have separate on/off controls.
- Jumping, impacts, platform destruction, enemies, and victory use locally generated arcade sound effects.
- All ten music tracks can also be played and downloaded individually through the project README.

## Controls and mobile use

- Keyboard: `A`/`D` or arrow keys, `W`/up arrow/space, `X` or `K`, `P` or Escape.
- Touch interface with separate controls for movement, jumping, and the ice pick.
- Fullscreen mode for supported desktop and mobile browsers.
- Adapted app-mode guidance for iPhone Safari, where standard element fullscreen is restricted.
- Installable web-app structure with manifest and app icons.

## Versions and updates

- The current version `1.0.0-beta.1` is visible on the start screen and in the level display.
- A versioned offline ZIP includes the complete game, all ten music tracks, and starters for macOS, Windows, and Linux.
- An automatic update check detects newer public beta and final releases.
- An available build is shown in the game with its version, release stage, and a direct GitHub link.
- Future builds require separate detailed German and English changelogs for every beta or final release.

## Privacy

- No user account, advertising, analytics, or tracking.
- The high score, graphics preset, level difficulties, and optional Mobile Ultra setting remain in the local browser.
- Music, graphics, and scripts are distributed with the game.
- Once on startup, the update checker requests the public GitHub Releases API. The game does not store or transmit save data or settings in this request.
- Personal data, credentials, local paths, and private files are not included in the release.

## Known beta limitations

- WebGPU Ultra depends on the browser, operating system, and graphics driver; unsupported devices automatically use the compatible renderer.
- Hardware ray tracing cannot be accessed directly through the currently used WebGPU features; reflections are screen-space effects.
- iPhone Safari does not provide one consistent native fullscreen mode for normal page elements; Home Screen app mode provides the best presentation.
- Ice-pick upgrades apply to the current run and reset when a new run begins.
- The update check requires an internet connection and may be skipped without a notice during GitHub outages or API limits; gameplay remains unaffected.
