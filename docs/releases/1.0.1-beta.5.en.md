# Skybreak Protocol 1.0.1-beta.5

This bugfix beta corrects the mobile start screen and documents the new compact controls with real smartphone screenshots.

## Mobile start menu

- The mobile start view is no longer vertically centred when its content exceeds the available game area, so menu areas at the top and bottom are not clipped.
- CHANGELOG and language switching now have their own top bar and can no longer overlap the start-level or difficulty selectors.
- Start level and difficulty remain immediately visible. On mobile, Challenge, pickaxe style, avatar, and robot model are grouped under **MORE OPTIONS** and can be expanded when needed.
- The level map is more compact, graphics, resolution, and frame-rate limit are grouped, and **RESET LOCAL PROFILE** remains reachable. On especially small displays, only the start view scrolls in a controlled way.

## Documentation and privacy

- The German and English GitHub landing pages now show the closed and expanded mobile menu as clickable screenshots.
- Both PDF manuals contain a dedicated page with the same two mobile views and explain the compact and expanded choices.
- The images contain only the public game interface. Embedded device colour profiles were removed; the files use the general sRGB colour space.
- No accounts, trackers, analytics services, private data, or additional network access were added. Game progress and all settings remain local to the browser.

Testing on additional real mobile devices remains useful, especially for very small portrait views and controls with enlarged text enabled.
