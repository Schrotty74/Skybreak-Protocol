# Skybreak Protocol 1.0.0-beta.4

This public beta turns every level into a complete 15-floor run and makes the visual quality modes easier to recognise. It also adds selectable internal rendering resolution and publishes the first desktop screenshots directly in the project README.

## Complete level runs

- Each of the ten levels is now a separate 15-floor ascent rather than a section of one long climb.
- A guardian drone blocks the exit at the top of every level and requires three ice-pick hits.
- The transition screen previews the name, color palette, platform material, and guardian signal of the next sector before the player selects an ice-pick upgrade.
- The robot now retains visible cracks, sparks, and sensor flicker after losing lives.
- Completing level 10 activates the transmission tower with a sunrise finale.

## Distinct platforms and Ultra mode

- All ten worlds now use distinct platform silhouettes as well as distinct colors and materials: industrial modules, capsules, corroded teeth, blades, waves, crystals, solar panels, phase shards, rift prisms, and summit crowns.
- Ultra now adds clearly visible volumetric neon shafts, dense foreground rain, animated bloom, and platform reflections.
- The graphics panel includes a persistent 720p, 1080p, or 4K internal render-resolution choice.
- The desktop fullscreen camera keeps the robot above the lower edge on shallow views.
- The desktop start screen now begins at the correct horizontal world position.

## Documentation and screenshots

- The English and German PDF manuals now document the render-resolution selector, distinctive platform forms, and visible Ultra effects.
- Two privacy-cleaned desktop screenshots have been added to both README pages as compact previews that open at full size when clicked.
- The screenshots contain no user account information, local paths, location data, or embedded EXIF profile.

## Compatibility, offline use, and privacy

- Existing local high scores, unlocked levels, difficulties, key bindings, and audio settings remain compatible.
- No account, analytics, advertising, tracking, or new network request was added.
- The release workflow rebuilds the versioned offline ZIP with all music tracks and desktop starters for macOS, Windows, and Linux.

## Known beta limitations

- The practical 4K render size depends on browser, display size, device pixel ratio, and available GPU limits.
- Ultra can still substantially increase heat and battery use on phones.
- Firefox may use the existing lighter WebGL2 fallback when WebGPU is unavailable.
