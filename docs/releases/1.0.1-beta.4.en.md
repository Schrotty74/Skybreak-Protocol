# Skybreak Protocol 1.0.1-beta.4

This beta tightens local profile control, cleans up the start screen, and adds clear protection and unlock rules.

## Start screen and controls

- The start screen now uses the two-colour neon **SKYBREAKPROTOCOL** title without an overlapping logo. The status line and version remain readable underneath.
- Graphics preset, resolution, frame-rate limit, and the desktop Showcase are grouped directly above **RESET LOCAL PROFILE**, keeping the full start view accessible without unnecessary scrolling.
- Key bindings are presented more compactly. **RESET KEYS** resets only customised keys; it does not erase game progress.
- **RESET LOCAL PROFILE** removes the local progress, unlocked content, cosmetic selection, local settings, and records for this browser. The game world then begins again at level 1.

## Unlocks and game rules

- A local unlock sequence supports testing: toggle sound effects off and on twice within five seconds, then turn music off within five seconds. It unlocks all levels, robots, and the hologram avatar only in this browser.
- The unlock confirmation is displayed clearly in the foreground without covering start-menu controls.
- An activated shield now has a time limit: Easy 8 seconds, Medium 6 seconds, and Hard 4 seconds. A hit still consumes the shield immediately.
- The local start environment has been hardened further so restarting a game does not cause an unintended return to the start screen.

## Visuals, testing, and documentation

- The desktop Showcase remains a separate 30-second benchmark for Ultra, 4K, and high frame rates. It is not part of mobile gameplay.
- The local macOS starter uses the development environment only for local testing; published offline ZIPs still contain an independent starter.
- The German and English READMEs, both PDF manuals, and the GitHub start image document the current start view, profile reset, unlock sequence, and shield duration.
- No accounts, trackers, analytics services, private data, or new external network access were added. Progress, unlocks, settings, and performance values remain local to the browser.

Complete functional testing on real desktop and mobile devices is still required, especially for visuals, frame rate, thermal behaviour, and battery life.
